# Adres verisi

Bu klasördeki `turkiye-2025.json`, [TurkiyeAPI](https://github.com/ubeydeozdmr/turkiye-api) 2025 sürümlü API veri setinden alınmıştır (MIT lisansı: LICENSE.txt). Ödeme sayfası bu dosyayı sitenin kendi sunucusundan yükler; harici API'nin çalışma durumuna bağlı değildir. Veri otomatik güncellenmez; yeni sürüm yayımlandığında il, ilçe, mahalle ve köy verilerini güncelleyip ilişki ve adetleri doğrulayarak yeniden dağıtın.
